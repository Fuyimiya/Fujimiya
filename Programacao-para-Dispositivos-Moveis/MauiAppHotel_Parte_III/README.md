## 📱 Sobre o Projeto

O MauiAppHotel é um aplicativo de gerenciamento de hospedagens desenvolvido para simular o cadastro, consulta e gerenciamento de informações relacionadas a hotéis, hóspedes e reservas.

Nesta terceira etapa do projeto foram implementadas melhorias estruturais na aplicação, aperfeiçoamento da interface gráfica e novas funcionalidades para tornar a experiência do usuário mais completa.

---

## 🎯 Funcionalidades

✅ Interface gráfica multiplataforma

✅ Navegação entre telas

✅ Cadastro de hóspedes

✅ Cadastro de reservas

✅ Exibição detalhada das informações do hotel

✅ Validação de dados

✅ Organização da aplicação em múltiplas páginas

✅ Melhorias na experiência do usuário

✅ Estruturação do projeto para futuras expansões
