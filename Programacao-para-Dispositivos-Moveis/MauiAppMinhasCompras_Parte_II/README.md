## 📱 Sobre o Projeto

O MauiAppMinhasCompras é um aplicativo desenvolvido para auxiliar no gerenciamento de listas de compras, permitindo o cadastro, consulta e organização de produtos de forma prática e intuitiva.

Nesta segunda etapa do projeto foram implementadas melhorias na interface, organização dos dados e novas funcionalidades para aprimorar a experiência do usuário.

---

## 🎯 Funcionalidades

✅ Interface gráfica multiplataforma

✅ Cadastro de produtos

✅ Exibição da lista de compras

✅ Edição de produtos cadastrados

✅ Remoção de produtos da lista

✅ Navegação entre telas

✅ Organização dos dados da aplicação

✅ Melhorias na usabilidade
