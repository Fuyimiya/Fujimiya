# 💪 MauiAppFit - Parte II

Aplicativo desenvolvido na disciplina de Programação para Dispositivos Móveis da Fatec Jaú utilizando .NET MAUI e MVVM.

---

## 📱 Sobre o Projeto

O MauiAppFit é um aplicativo para acompanhamento de atividades físicas e hábitos saudáveis.

Nesta etapa foi implementada a arquitetura MVVM (Model-View-ViewModel), melhorando a organização e manutenção do código.

---

## 🎯 Funcionalidades

✅ Cadastro de atividades

✅ Exibição de dados em ListView

✅ Atualização de informações

✅ Arquitetura MVVM

✅ Interface multiplataforma

---

## 🛠️ Tecnologias Utilizadas

- .NET MAUI
- C#
- XAML
- MVVM

---

## ⚠️ Observação

O aplicativo está concluído.

Foi identificado um comportamento incorreto da ListView no Android quando utilizada dentro de uma RefreshView. Por esse motivo, a ListView foi posicionada fora da RefreshView para manter o funcionamento adequado.
