## 📱 Sobre o Projeto

O MauiAppMeuCombustivel é um aplicativo desenvolvido para auxiliar o usuário na escolha entre abastecer com gasolina ou etanol, realizando cálculos automáticos com base nos valores informados.

Nesta etapa foi implementada a arquitetura MVVM (Model-View-ViewModel), promovendo melhor organização, separação de responsabilidades e manutenção do código.

---

## 🎯 Funcionalidades

✅ Cadastro do preço da gasolina

✅ Cadastro do preço do etanol

✅ Cálculo automático da melhor opção

✅ Exibição do resultado na tela

✅ Arquitetura MVVM

✅ Interface multiplataforma
