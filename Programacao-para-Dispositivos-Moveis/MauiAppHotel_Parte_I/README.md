## 📱 Sobre o Projeto

O MauiAppHotel é um aplicativo de gerenciamento de hospedagens desenvolvido para simular o cadastro e a consulta de informações de hotéis.

Nesta primeira etapa do projeto foram implementadas as telas iniciais, componentes visuais e funcionalidades básicas da aplicação utilizando .NET MAUI.

---

## 🎯 Funcionalidades

✅ Interface gráfica multiplataforma

✅ Navegação entre telas

✅ Cadastro de hóspedes

✅ Cadastro de reservas

✅ Exibição de informações do hotel

✅ Estrutura inicial do projeto
