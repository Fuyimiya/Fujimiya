# 🌦️ AppTempoAgora

Aplicativo desenvolvido na disciplina de Programação para Dispositivos Móveis.

## 📱 Sobre

Aplicativo que consulta a previsão do tempo utilizando geolocalização e serviços meteorológicos.

## 🎯 Funcionalidades

- Localização atual
- Temperatura em tempo real
- Umidade do ar
- Condições climáticas

## 🛠️ Tecnologias

- Java
- Android Studio
- Geolocation
- API de clima
