# 🛒 MauiAppMinhasCompras - Parte I

Aplicativo desenvolvido na disciplina de Programação para Dispositivos Móveis da Fatec Jaú utilizando .NET MAUI.

---

## 📱 Sobre o Projeto

O MauiAppMinhasCompras é um aplicativo desenvolvido para auxiliar no gerenciamento de listas de compras, permitindo o cadastro e a organização de produtos de forma simples e prática.

Nesta primeira etapa do projeto foram implementadas as telas iniciais, componentes visuais e funcionalidades básicas da aplicação utilizando .NET MAUI.

---

## 🎯 Funcionalidades

✅ Interface gráfica multiplataforma

✅ Cadastro de produtos

✅ Exibição de lista de compras

✅ Navegação entre telas

✅ Estrutura inicial da aplicação

✅ Organização básica dos dados

---
