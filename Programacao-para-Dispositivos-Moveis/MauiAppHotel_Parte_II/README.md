# 🏨 MauiAppHotel - Parte II

Aplicativo desenvolvido na disciplina de Programação para Dispositivos Móveis da Fatec Jaú utilizando .NET MAUI.

---

## 📱 Sobre o Projeto

O MauiAppHotel é um aplicativo de gerenciamento de hospedagens desenvolvido para simular o cadastro e a consulta de informações de hotéis.

Nesta segunda etapa do projeto foram implementadas melhorias na interface, tratamento de dados e novas funcionalidades relacionadas ao gerenciamento de hóspedes e reservas.

---

## 🎯 Funcionalidades

✅ Interface gráfica multiplataforma

✅ Navegação entre telas

✅ Cadastro de hóspedes

✅ Cadastro de reservas

✅ Exibição detalhada das informações do hotel

✅ Validação de dados

✅ Organização da aplicação em múltiplas páginas

---
