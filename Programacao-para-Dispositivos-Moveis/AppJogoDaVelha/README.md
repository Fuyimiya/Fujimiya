## 📱 Sobre o Projeto

O MauiAppJogoDVelha é uma versão mobile do clássico jogo da velha desenvolvida com .NET MAUI.

Nesta etapa foi implementada a arquitetura MVVM (Model-View-ViewModel), promovendo melhor organização, separação de responsabilidades e manutenção do código.

---

## 🎯 Funcionalidades

✅ Tabuleiro interativo 3x3

✅ Alternância automática entre os jogadores X e O

✅ Verificação automática de vitória

✅ Detecção de empate

✅ Reinício da partida

✅ Arquitetura MVVM

✅ Interface multiplataforma
