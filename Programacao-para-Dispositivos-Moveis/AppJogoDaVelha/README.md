# 🎮 AppJogoDaVelha

Aplicativo Android desenvolvido na disciplina de Programação para Dispositivos Móveis da Fatec Jaú.

---

## 📱 Sobre o Projeto

O AppJogoDaVelha é uma versão digital do clássico jogo da velha, permitindo que dois jogadores disputem partidas diretamente no dispositivo móvel.

---

## 🎯 Funcionalidades

- ✅ Tabuleiro interativo 3x3
- ✅ Alternância entre jogador X e O
- ✅ Verificação automática de vitória
- ✅ Reinício da partida

---

## 🛠️ Tecnologias Utilizadas

- Java
- Android Studio
- XML
- GitHub
