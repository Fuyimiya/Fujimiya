# 🎮 MauiAppJogoDaVelha

Aplicativo desenvolvido na disciplina de Programação para Dispositivos Móveis da Fatec Jaú utilizando .NET MAUI e MVVM.

---

## 📱 Sobre o Projeto

O MauiAppJogoDVelha é uma versão mobile do clássico jogo da velha desenvolvida com .NET MAUI.

Nesta etapa foi implementada a arquitetura MVVM (Model-View-ViewModel), promovendo melhor organização, separação de responsabilidades e manutenção do código.

---

## 🎯 Funcionalidades

✅ Tabuleiro interativo 3x3

✅ Alternância automática entre os jogadores X e O

✅ Verificação automática de vitória

✅ Detecção de empate

✅ Reinício da partida

✅ Arquitetura MVVM

✅ Interface multiplataforma

---

## 🛠️ Tecnologias Utilizadas

* .NET MAUI
* C#
* XAML
* MVVM

## 🚀 Objetivo Acadêmico

Projeto desenvolvido para aplicar conceitos de desenvolvimento multiplataforma com .NET MAUI, utilizando o padrão MVVM e implementando a lógica completa do jogo da velha.
