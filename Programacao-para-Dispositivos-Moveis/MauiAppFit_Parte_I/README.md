# 💪 MauiAppFit - Parte I

Aplicativo desenvolvido na disciplina de Programação para Dispositivos Móveis da Fatec Jaú utilizando .NET MAUI.

---

## 📱 Sobre o Projeto

O MauiAppFit é um aplicativo voltado ao acompanhamento de atividades físicas e hábitos saudáveis.

Nesta primeira etapa do projeto foram implementadas as telas iniciais, componentes visuais e funcionalidades básicas da aplicação utilizando .NET MAUI.

---

## 🎯 Funcionalidades

✅ Interface gráfica multiplataforma

✅ Navegação entre telas

✅ Cadastro de atividades físicas

✅ Exibição de informações ao usuário

✅ Estrutura inicial do projeto

---

## 🛠️ Tecnologias Utilizadas

* .NET MAUI
* C#
* XAML
* Visual Studio

---

## 📂 Estrutura do Projeto

```txt
MauiAppFit
├── Models
├── Views
├── Resources
└── App.xaml
```

---

## 🚀 Objetivo Acadêmico

Projeto desenvolvido para introduzir os conceitos de desenvolvimento multiplataforma utilizando .NET MAUI, explorando a criação de interfaces gráficas e organização de aplicações móveis.
