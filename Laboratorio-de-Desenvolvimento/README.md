# ♻️ EcoFluxo

Sistema desenvolvido para monitoramento de ecopontos e lixeiras inteligentes, permitindo o gerenciamento de resíduos, acompanhamento dos níveis de preenchimento e envio de notificações automáticas.

---

## 📱 Sobre o Projeto

O EcoFluxo é uma plataforma web composta por Frontend e Backend, desenvolvida para auxiliar na gestão sustentável de resíduos urbanos.

O sistema permite cadastrar ecopontos, monitorar lixeiras inteligentes, visualizar informações geográficas e receber notificações quando os recipientes atingem níveis críticos de ocupação.

---

## 🎯 Funcionalidades

✅ Cadastro de usuários

✅ Controle de acesso por perfil

✅ Cadastro de ecopontos

✅ Cadastro de lixeiras inteligentes

✅ Monitoramento do nível de preenchimento

✅ Sistema de notificações automáticas

✅ Dashboard com gráficos

✅ Visualização em mapa interativo

✅ Consulta de localização dos ecopontos

✅ Gerenciamento de resíduos recicláveis

## 📊 Principais Recursos

### 🗺️ Ecopontos

Permite cadastrar e localizar pontos de coleta seletiva utilizando coordenadas geográficas.

### 🗑️ Lixeiras Inteligentes

Monitoramento dos níveis de preenchimento de cada recipiente.

### 🔔 Notificações

Envio automático de alertas quando uma lixeira atinge níveis críticos.

### 📈 Dashboard

Exibição gráfica de informações para acompanhamento do sistema.
