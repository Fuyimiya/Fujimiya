🌱 Vasos Inteligentes

Projeto desenvolvido com foco em automação e monitoramento de plantas, utilizando tecnologias web para acompanhamento das condições dos vasos em tempo real.

---

📱 Sobre o Projeto

O Vasos Inteligentes é uma aplicação desenvolvida para auxiliar no monitoramento de plantas, permitindo acompanhar informações importantes como umidade do solo, status dos vasos e condições de cultivo.

O sistema foi desenvolvido com interface web moderna, proporcionando uma experiência simples e intuitiva para o usuário.

---

🎯 Funcionalidades

✅ Monitoramento dos vasos

✅ Visualização das informações em tempo real

✅ Interface responsiva

✅ Gerenciamento de plantas

✅ Acompanhamento das condições do solo

✅ Organização dos dados em painel web
