# 🌐 Desenvolvimento Web

# 🌱 Vasos Inteligentes

Um sistema inteligente voltado para o monitoramento e automação do cuidado de plantas e cultivos, integrando sensores, exibição de dados climáticos e controle automatizado.

---

## 🚀 Sobre o Projeto

O **Vasos Inteligentes** é uma aplicação web desenvolvida para monitorar a saúde de plantas em tempo real. O sistema coleta dados ambientais (como umidade do solo, temperatura e incidência de luz) para garantir que cada planta receba o cuidado ideal, automatizando processos como a irrigação.

### 📋 Funcionalidades Principais

- **Monitoramento em Tempo Real:** Visualização de gráficos com os níveis de umidade do solo, temperatura ambiental e luminosidade.
- **Alertas e Notificações:** Avisos automáticos quando a planta precisar de água ou quando as condições climáticas estiverem desfavoráveis.
- **Histórico de Regas:** Registro detalhado de quando a planta foi irrigada.
- **Dashboard Web:** Interface responsiva para gerenciar múltiplos vasos ou culturas simultaneamente.

---

## 🛠️ Tecnologias Sugeridas

Dependendo do escopo do projeto, aqui está uma stack recomendada para o desenvolvimento:

- **Frontend:** HTML5, CSS3 (ou Bootstrap/Tailwind), JavaScript (ES6+).
- **Backend:** Node.js / Express (ou PHP, dependendo da disciplina acadêmica).
- **Banco de Dados:** SQLite ou MySQL para armazenar o histórico dos sensores e configurações dos vasos.
- **Integração (Opcional/IoT):** Simulação de sensores via requisições HTTP/API ou uso de dados de clima externos.
